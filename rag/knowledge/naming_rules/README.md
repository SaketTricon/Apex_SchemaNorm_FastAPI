# Naming rules knowledge

This folder contains standards for translating ambiguous or legacy source field names into cleaner target schema names.

## Included topics

- common customer and address name mappings
- naming conventions for IDs, codes, and statuses
- source-to-target conversion rules and caveats

## Best practice

The target schema should use names that are readable, internally consistent, and traceable back to the original fields. Good naming improves both schema quality and downstream LLM recommendations.
