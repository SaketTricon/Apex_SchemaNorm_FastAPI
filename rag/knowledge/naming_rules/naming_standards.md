# Naming Standards

Use clear and consistent names for target database columns.

Recommended mappings include:

- cust_id -> customer_id
- cust_nm -> customer_name
- cust_name -> customer_name
- addr1 -> address_line_1
- addr2 -> address_line_2
- zip -> postal_code
- zipcode -> postal_code
- phone_no -> phone
- email_id -> email
