# Industry schema references

This folder contains representative schema examples for common business domains.

## Included examples

- retail customer and order patterns
- healthcare encounter and patient structures

## Purpose

These examples help the LLM recognize recurring design structures and compare the source profile to a realistic normalized target model.

## Guidance

Use these documents as a reference for structure, not as a hard-coded design requirement. The final target schema should align with the actual source data, cardinality, and business rules.
